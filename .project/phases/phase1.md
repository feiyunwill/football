# Phase 1: 帧同步联机稳定版

## 目标

实现完整的帧同步联机系统，支持 4 人联机对战，确保确定性 100%。

## 成功条件

- 4 人联机无 crash
- 确定性 100%（跨平台 hash 一致）
- 延迟 <30ms
- 重连成功率 >95%

## 里程碑

| 里程碑 | 目标 | 成功条件 | 依赖 | 状态 |
|--------|------|----------|------|------|
| ms-1.1 | 基础协议稳定性 | 100 场 e2e 测试无失败 | - | 进行中 |
| ms-1.2 | 确定性基础 | 全定点数 + 确定性 RNG + 跨平台 hash 100% 一致 | ms-1.1 | 待开始 |
| ms-1.3 | 预测回滚 | 客户端预测 + 服务器权威 + 回滚校正 | ms-1.2 | 待开始 |
| ms-1.4 | 动态追帧 | 网络抖动下自动追帧，延迟 <30ms | ms-1.3 | 待开始 |
| ms-1.5 | 外挂校验 | 服务器验证输入合法性，拒绝非法输入 | ms-1.3 | 待开始 |
| ms-1.6 | 逻辑渲染分离 | 逻辑帧率固定，渲染可插值 | ms-1.3 | 待开始 |
| ms-1.7 | 渲染平滑 | 插值/外推使画面流畅 | ms-1.6 | 待开始 |
| ms-1.8 | 性能优化 | 60fps，延迟 <30ms | ms-1.4, ms-1.5, ms-1.7 | 待开始 |

## 时间线

```
第 1-2 周: ms-1.1 (协议稳定性)
第 3-4 周: ms-1.2 (确定性基础)
第 5-6 周: ms-1.3 (预测回滚)
第 7-8 周: ms-1.4 (动态追帧) + ms-1.5 (外挂校验) + ms-1.6 (逻辑渲染分离)

```
