# 项目总览

## 最终目标

**商业级 3D 足球对战游戏**

### 技术特性
- **C++23** 现代架构
- **确定性帧同步联机**
- **ECS 组件化系统**
- **AI 训练支持**（Python/C++）
- **内置高性能 AI**
- **Headless 服务端校验**

### 帧同步高级特性
- 预测回滚（Predictive Rollback）
- 动态追帧（Dynamic Catch-up）
- 外挂校验（Cheat Validation）
- 逻辑与渲染分离
- 逻辑回滚
- 渲染平滑（插值/外推）
- 全定点数（Fixed-point Arithmetic）
- 确定性伪随机数（Deterministic PRNG）
