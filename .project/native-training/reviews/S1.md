## 整体核对

- 支持范围由 COMPATIBILITY.md 约束；单队 1–11 人、default/v2 动作、
  simple115/simple115v2、scoring/checkpoints 和可选四帧堆叠有实际对照。
  非法输入、fork/owner、终止和失败释放路径有专门合约。
- 两种布局共享球、持球人、active 与 game mode 编码；稀疏阵容的 compact
  偏移和 fixed 填充值分别检查，右队方向与奖励视角一致。
- checkpoint 按 agent 保存 0–10 的计数；距离和阈值使用 double，奖励按
  float32 累加，进球补齐剩余奖励，reset 清空计数。
- 四帧 ring 在 reset 重复初始帧，按返回 transition 更新一次，输出从旧到新。
  scalar/batch 共用 advance；batch 预检全部动作并返回首个终态的完整前缀。
- ObservationBuffer 有 115/460 两种宽度、256×11 行上限和连续存储，
  绑定按实际宽度创建 NumPy shape/stride；输出独立拥有数据，copy assignment
  先复制后交换。终态历史、reset、非法后缀和返回值生命周期均覆盖。
- 释放 GIL 期间动作和场景输入由 C++ 拥有，返回 NumPy 在重获 GIL 后分配。
  mutex 串行化同一原生对象；这不证明 GameEnv 可同进程多线程并行运行。
