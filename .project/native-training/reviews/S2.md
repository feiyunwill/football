## 全局核对

- FTRN v1 嵌套现有 FSTA v2；FPTR v1 是 Python JSON/bytes 外层。每层有
  版本、精确长度、CRC 与容量检查；动态集合在分配前检查数量。
  格式契约以实际 wire corruption/truncation/超限输入验收，不使用 pickle。
- 场景身份显式编码 reset 输入字段，包含队伍、角色/初始位置、seed、结束
  条件等；不复制 C++ struct padding 或 derived cache。选项、人数、cadence、
  dimensions、源文件/编译参数/实际 data manifest 验证先于 kernel mutation。
- kernel RNG/比赛/控制器状态、checkpoint、score/mode/possession 历史、ready
  和四帧 ring 都有归属。wire 使用 oldest→newest 顺序，恢复 cursor=0；不会
  在恢复时调用 physics tick、奖励结算或追加观测。最新帧与恢复内核观测核对。
- 恢复前准备所有训练数组；kernel + postcondition 失败恢复旧 kernel/config，
  训练侧以 noexcept assignment/swap 最后提交。严重回滚失败关闭内核；Python
  通过 is_closed 释放真实预约并更新 lifecycle。故障测试不假装制造 C++ OOM。
- Python PCG64 与 episode/config 被严格检查和提前准备；终态保持 reset-needed。
  wrapper-aware API 记录 TimeLimit、OrderEnforcing、PassiveEnvChecker 的值和
  历史数组，参数/次序/版本匹配，未知 wrapper 明确拒绝；wrapper 提交失败
  回滚 raw 与 wrapper，失败回滚则关闭。policy/space RNG/callback 为调用者状态。
- GIL 释放期间只使用 bounded C++ owned 输入/结果；JSON 和 NumPy 重建在
  Python 侧。owner 检查先于文件、RNG、配置变化；不承诺 C++ 跨 fork 或同进程
  多线程并行 GameEnv。新进程恢复实际采用独立 Python 进程。
- 文件先同目录临时 write/flush/fsync，再 replace/目录同步；替换前失败保留
  旧目标。实际 kill-writer 测试通过。替换后异常可能留下完整新文件；被杀死
  的 writer 可能留下私有临时文件，文档没有承诺不存在孤儿文件。

## 跨组件影响

默认 Python backend 的分发与数值语义保留，原有 9 项 Gym 实际引擎回归包含
渲染、向量环境、legacy 包装与释放。GameEnv::get_info 的 tracker 改为异常
平衡的 RAII；TeamData 泄漏修复也作用于旧后端，构造 ID 顺序及 RNG 次数保留。
没有重写网络协议、录制或物理算法；未重新完成全产品网络/soak/渲染预算门禁。

bindings OFF 不依赖 Python，新头/实现与契约已登记，快照 identity 不依赖
Python bindings 开关；当前 Python/native core artifact 哈希相同。native public
接口需重新编译，不承诺稳定二进制 ABI。单配置 Linux/WSL 工具链有实际证据；
multi-config generator、系统依赖组合、跨构建迁移、wheel 和其他平台由 S5
明确验证，不能把本次 staging 当实际安装/跨平台结果。

metadata CRC 用于检测损坏，不是来源认证；版本不提供历史迁移策略。kernel
digest 仍不代表完整训练状态。实际数据文件校验有固定容量且不在 step 热路径，
其成本属于后续 profile；当前正确性/回放结果不暗示采样吞吐加速。
