# ms-16.6: 自适应预测上限

## 目标

将 Python 侧的自适应预测逻辑接入 C++ 客户端，根据 RTT 动态调整预测帧数。

## 成功条件

- [ ] C++ 客户端读取 RTT 数据
- [ ] 根据 RTT 动态调整 `MAX_PREDICT_AHEAD_FRAMES`
- [ ] 高延迟时增加预测窗口，低延迟时减少
- [ ] 编译通过

## 技术方案

### 实现

1. 在 `ClientState` 或 `UXOptimizer` 中添加自适应逻辑
2. 根据 `RTTTracker` 的 smoothed RTT 调整预测上限
3. 添加最小/最大限制（1~5帧）

### 关键文件

- 修改：`engine/src/frame_sync/client_state.hpp`
- 修改：`engine/src/frame_sync/integrated_client.cpp`
- 修改：`engine/src/frame_sync/ux_optimizer.hpp`
