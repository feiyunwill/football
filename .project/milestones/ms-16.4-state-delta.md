# ms-16.4: 状态 Delta 压缩

## 目标

为完整游戏状态快照实现 Delta 压缩，减少网络传输带宽。

## 成功条件

- [ ] 实现 `StateDeltaEncoder` 类
- [ ] 对比前后两帧状态，只传输差异部分
- [ ] 压缩率 >50%（典型场景）
- [ ] 解压无损还原完整状态
- [ ] 编译通过
- [ ] 单元测试通过

## 技术方案

### 算法

1. 基线帧：全量传输完整状态
2. 后续帧：计算与上一帧的 diff
3. 使用 XOR + run-length 编码压缩 diff
4. 接收端根据基线帧 + diff 序列重建状态

### 实现

```cpp
// engine/src/frame_sync/state_delta_codec.hpp
class StateDeltaCodec {
 public:

  std::string baseline_;
};
```
