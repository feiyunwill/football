# ms-16.3: 视觉外推

## 目标

在客户端延迟或丢包时，通过外推预测球员位置，避免渲染卡顿。

## 成功条件

- [ ] 基于速度/加速度的外推算法
- [ ] 外推结果在权威帧到达后平滑修正
- [ ] 外推不超过合理边界（球场范围、最大速度）
- [ ] 编译通过
- [ ] e2e 测试通过

## 技术方案

### 算法

1. 记录每个实体的历史位置和时间戳
2. 计算速度向量（最近 N 帧）
3. 根据 `(当前时间 - 最后确认时间) * 速度` 外推位置
4. 权威帧到达后，使用 lerp 平滑修正到正确位置

### 实现

- 扩展 `Interpolator` 类，添加 `Extrapolate()` 方法
- 在 `ClientState` 中跟踪每个实体的外推状态
- 添加外推边界检查（球场范围、最大速度限制）
