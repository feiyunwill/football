## 目标

实现客户端的动态追帧机制：当客户端落后于服务器时加速追赶，当抖动导致帧间隔不均匀时平滑输出。

- [x] 自适应帧率：根据网络延迟动态调整客户端帧率
- [x] 超前保护：当客户端超前时自动减速等待

- [x] 与 Python 客户端行为对齐

## 实现细节

### 追帧算法

```
每帧循环:
  1. 计算落后帧数 = server_frame_id - local_frame_id
  2. 如果落后 > THRESHOLD:
     a. 本 tick 处理 min(落后帧数, MAX_CATCHUP_FRAMES) 帧
     b. 每帧跳过渲染，只执行逻辑
  3. 如果落后 <= THRESHOLD:
     a. 正常处理 1 帧
  4. 如果超前 > THRESHOLD:
     a. 本 tick 不处理帧，等待服务器
```

### 抖动平滑

```
统计:
  - 帧到达间隔的移动平均
  - 抖动 = |实际间隔 - 期望间隔|
  - P95 抖动用于告警

平滑策略:
  - 如果抖动 < 阈值: 正常渲染
  - 如果抖动 > 阈值: 使用插值/外推平滑
```
