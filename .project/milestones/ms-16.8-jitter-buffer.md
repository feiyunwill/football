# ms-16.8: 自适应抖动缓冲

## 目标

根据网络抖动状况动态调整客户端的输入缓冲大小。

## 成功条件

- [ ] 读取 `JitterStats` 推荐值
- [ ] 动态调整缓冲帧数（1~5帧）
- [ ] 抖动高时增加缓冲，抖动低时减少缓冲
- [ ] 编译通过

## 技术方案

### 实现

1. 在客户端 tick 中读取 `JitterStats::recommended_buffer_frames`
2. 平滑调整缓冲大小（避免频繁跳变）
3. 缓冲变化时通知插值/外推模块

- 修改：`engine/src/frame_sync/client_state.hpp`
- 修改：`engine/src/frame_sync/integrated_client.cpp`
