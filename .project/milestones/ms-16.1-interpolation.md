# ms-16.1: 队伍/裁判插值

## 目标

为球员、队伍、裁判添加插值支持，使渲染在帧率不稳定或网络抖动时保持平滑。

## 成功条件

- [ ] `Match::SaveInterpolationState()` 保存所有实体插值状态
- [ ] `Match::PutInterpolated()` 对所有实体应用插值
- [ ] 球员位置/旋转使用 lerp/slerp 插值
- [ ] 队伍整体位置插值
- [ ] 裁判位置插值
- [ ] 编译通过
- [ ] e2e 测试通过

## 技术方案

### 现有代码分析

- `ball.cpp` 已实现插值（line 604-607）：位置 lerp，旋转 slerp
- `match.cpp` 有 TODO 桩代码（line 1505-1519）
- `Interpolator` 类已完整实现（`interpolator.hpp`）

### 实现步骤

1. 在 `Match` 类中添加 `InterpolationState` 结构体，包含所有球员/队伍/裁判的状态
2. 实现 `SaveInterpolationState()` 遍历所有实体保存状态
3. 实现 `PutInterpolated(float t)` 遍历所有实体应用插值
4. 在渲染循环中调用插值（需要与 `UXOptimizer` 集成）
