# ms-17.3: 观战模式

## 目标
添加观战者角色（只读，不发送输入），观战者接收所有玩家的 authoritative frames，支持多个观战者同时连接。

## 实现
1. `spectator.hpp` — SpectatorClient 类：连接服务器、发送 SpectatorJoin、接收 AuthoritativeFrame/StateHash/StateSnapshot
2. 在 protocol.hpp 添加 `SpectatorJoin = 14` 消息类型
3. 在 integrated_server.cpp 支持 SpectatorJoin（不分配 slot，加入 spectators_ 列表）
4. 广播时同时发送给 players 和 spectators

## 测试
- `spectator_test.cpp`：纯逻辑单元测试，验证 SpectatorClient 状态机、帧缓冲、统计
