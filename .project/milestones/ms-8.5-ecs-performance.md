## 实现细节

### 性能优化方向

1. **组件池批量插入优化**
   - 移除 `Set()` 方法中的每次排序
   - 添加 `SortIfNeeded()` 方法在批量插入后统一排序
   - 减少排序开销，提高批量添加性能

2. **批量添加支持**
   - 添加 `FlushBatchAdds<T>()` 方法
   - 在批量添加组件后统一排序
   - 减少每帧的排序次数

3. **多组件查询优化**
   - 添加三组件 `ForEach<T1, T2, T3>()` 方法
   - 使用最小池作为主遍历池，减少遍历次数
   - 提高多组件查询性能

4. **系统实现优化**
   - 更新 `SyncPlayerStateSystem` 使用批量操作
   - 更新 `SyncHumanoidStateSystem` 使用批量操作
   - 减少每帧的排序开销
