# ms-16.2: 确定性 PRNG 模块

## 目标

提取确定性伪随机数生成器为独立模块，保证跨平台一致性。

## 成功条件

- [ ] 实现 `DeterministicPRNG` 类（xorshift128+）
- [ ] 支持 seed 设置、next、range 等接口
- [ ] 跨平台位精确一致（已有 `fixed_point_determinism_test` 作为参考）
- [ ] 替换引擎中关键路径的 RNG 调用
- [ ] 单元测试覆盖
- [ ] 编译通过

## 技术方案

### 实现

```cpp
// engine/src/frame_sync/deterministic_prng.hpp
class DeterministicPRNG {
 public:
  explicit DeterministicPRNG(uint64_t seed);
  uint64_t next();
  uint32_t next_uint32();
  float next_float();  // [0.0, 1.0)
  int range(int min, int max);
 private:
  uint64_t state_[2];
};
```

### 算法选择

- xorshift128+：速度快、统计质量好、实现简单
- 已在 `fixed_point_determinism_test.cpp` 中有 xorshift32 参考
