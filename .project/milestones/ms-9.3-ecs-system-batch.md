## 实现细节

### 新增批处理系统

1. **SystemBatch<Components...>** - 通用系统批处理模板
   - 支持任意数量的组件类型
   - 支持多个系统合并执行
   - 使用查询接口优化遍历

2. **PlayerSystemBatch** - 球员系统批处理
   - 合并 PlayerState 和 HumanoidState 系统
   - 同一次遍历更新两个组件

3. **OfficialsSystemBatch** - 裁判组系统批处理
   - 合并裁判组相关系统

4. **PossessionStatsBatch** - 控球统计批处理
   - 合并两个队伍的控球统计

### 优化点

1. **减少系统调用次数** - 将多个系统合并为一个批处理
2. **减少实体遍历次数** - 同一次遍历更新多个组件
3. **提高缓存命中率** - 连续访问相同实体的组件
