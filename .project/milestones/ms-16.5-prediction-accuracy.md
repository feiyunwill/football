# ms-16.5: 预测准确率追踪

## 目标

将 `UXOptimizer` 的预测准确率接口接入实际回滚路径，实时监控预测质量。

## 成功条件

- [ ] 回滚时调用 `RecordPrediction(correct/incorrect)`
- [ ] 预测准确率可在运行时查询
- [ ] 准确率数据可用于自适应调整
- [ ] 编译通过

## 技术方案

### 实现

1. 在 `IntegratedFrameSyncClient::tick()` 中，权威帧到达时对比预测输入与实际输入
2. 调用 `UXOptimizer::RecordPrediction()` 记录结果
3. 提供查询接口获取当前准确率

- 修改：`engine/src/frame_sync/integrated_client.cpp`
- 修改：`engine/src/frame_sync/ux_optimizer.hpp`
- 修改：`engine/src/frame_sync/integrated_client_udp.cpp`
