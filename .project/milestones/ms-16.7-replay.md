# ms-16.7: 回放系统

## 目标

实现帧同步会话的录制和回放功能。

## 成功条件

- [ ] 录制所有帧输入和状态
- [ ] 回放时按序重放输入，状态一致
- [ ] 支持快进/快退
- [ ] 回放文件大小合理（使用 Delta 压缩）
- [ ] 编译通过
- [ ] e2e 测试通过

## 技术方案

### 实现

1. 录制模式：每帧记录 `{frame_id, inputs[], state_hash}`
2. 回放模式：按序应用输入，验证状态哈希一致
3. 使用 Delta 压缩（ms-16.4）减小文件大小

### 文件格式

```
ReplayHeader: {version, seed, player_count, frame_count}
FrameData[]: {frame_id, delta_inputs[], delta_state}
```
