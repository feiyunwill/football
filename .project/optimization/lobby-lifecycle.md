# 大厅到比赛生命周期门禁

`lobby_lifecycle` 对应 `task-23.1.2.1`。大厅版本 1 的整数、房间配置与元数据现在使用固定长度的小端字节布局；保留既有 x86 报文长度，保留字节写零，解码时不依赖 C++ 结构体填充。`EndGame` 只能由当前房主提交，服务端发出 `GameEnded` 后回收房间并释放双方的房间归属；玩家可在原连接上再次建房、加入、准备和开赛。房主应在实际比赛完成后发送结束命令。

运行 `python3 .project/checks/lobby_lifecycle.py` 会构建并执行 57 项 C++ 协议、房间、容量及真实 socket 测试，71 项 Python 大厅/联机/比赛结束测试，以及 4 项真实 GameEnv 的联机与自然结束测试；任何失败、跳过或关键场景缺失都会阻止门禁通过。原生场景分别覆盖 TCP 和 UDP 的最终权威帧、结束确认与资源回收。

每次运行的命令日志、SHA-256 和汇总报告保存在 `.project/optimization/benchmarks/lobby-lifecycle-*`。此门禁单独通过不代表网络计划或里程碑通过；它们还依赖手感、输入窗口、重连和真实网络故障矩阵。
