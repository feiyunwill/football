# 架构集成契约

2026-09-09，`task-20.1.2.2`。完成状态以 quality.py 当前源码指纹及正式证据为准。

GameEnv 是生命周期入口。运行中的环境可通过 `pause()` 冻结，重复调用幂等；`resume()` 恢复，重复恢复运行状态幂等。暂停期间 `step()`、`StepWithInput()`、`action()` 不推进逻辑、不更新输入；观察、渲染和快照仍可使用。暂停以新增的 `game_paused` 状态写入快照，保留此前枚举值的编号。恢复后继续运行应与未暂停的相同输入轨迹一致。

`finish()` 标记比赛结束并保留最终观察、图像和快照；结束后拒绝输入、推进、暂停和恢复，`reset()` 可以开始新比赛。未启动或已销毁的实例拒绝生命周期操作。`close()` 继续保持幂等、资源逆序释放与随后重新启动的能力。Python 绑定公开相同接口；已有 Python episode 结束判定保持由包装层执行。

原生单机共用可测试的 SDL 事件处理：P/Esc 暂停或恢复，忽略按键重复，失焦时暂停，Q/窗口关闭结束比赛。达到配置的 episode 长度后正常结束循环。此阶段通过真实 SDL offscreen 驱动窗口/GL context 和 SDL_PushEvent/SDL_PollEvent 验证该事件路径，不等同于目标桌面、手柄或显示器上的交互验收。

错误边界：

- 控制器索引先校验在 0..10 内，动作编号先校验再转换枚举；非 sticky 动作查询抛异常，不退出宿主。
- 场景在创建资源或破坏现有比赛前校验：每队 1..11 人、0..11 控制槽、足够可控球员；有限且不超过 10 个场地单位的坐标；难度 0..1，正 episode 长度、非负半场步数。
- 每步物理 tick 支持 1..1000；渲染尺寸各 1..8192，总像素不超过 16,777,216。公共配置对象仍供旧调用方配置；调用方必须串行修改，不能与 API 并发写入这些公开字段。
- 网络输入要求恰好一整帧，验证所有槽的布局、引用、方向、有限浮点和按键掩码后再写入控制器；失败不改变先前输入或推进逻辑。0 控制槽可使用空帧。暂停时忽略输入帧。应用有效帧时启用相应控制器，与本地 action 行为一致；通过两侧各两个控制槽、40 帧本地动作/权威帧逐帧摘要对照验收。
- SDL/EGL 初始化、窗口、context、配置及 GL 函数加载失败抛异常；字体/描边字体失败同样进入 GameEnv 的清理和重试路径。
- 截图以紧密 RGB 行写入已分配字节缓冲区，恢复此前的 GL pack alignment；回归包含 321×181 的实际截图。
- 半场阈值用 64 位乘法，避免默认禁用半场的哨兵值发生有符号整数溢出；覆盖真实第二半场切换及默认值保持第一半场。
