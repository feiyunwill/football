# 人工转身响应候选

基于 `a7d49b8` 的隔离候选保留真实触球，仅对比赛中的人工反向转身短暂提高有界减速能力。两次完整窗口检查均为 60/60 响应、449 项断言通过：速度/可见 p95 分别为 45.032/48.207 ms 和 43.167/45.437 ms。

正常与反向快照、真实触球、headless 架构契约在 Release 和 ASan/UBSan 下通过。这些定向结果不能替代合入后对当前源码的完整依赖验收。

两轮 JSON、JSONL、日志、动作及权威记录的紧凑归档和完整归档哈希见 `evidence/handfeel-candidate-20261001.json`；完整 PPM 捕获保留在本地原始归档中。紧凑归档省略了 PPM，不能用于逐像素视觉复核。
