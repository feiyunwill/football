# O23S：单一配合阶段credit重置干预

前序平均候选95.7%确认的提升区间下限等于0，判定失败且不重新确认相同候选。当前阶段回到有界推理机制实验，不追加训练、不搜索平均窗口。

定向源码审阅：BalancedInference只接收19动作概率，跨决策累计credit；CooperationObservation在首次完成传球时将padding历史标志从-1切为+1，控制器本身不接收该阶段。固定五模型各20个旧验证案例的只读轨迹共5072决策，99次首次阶段切换中55次历史credit改变了首个动作；该子集99/100进球，尚无证据表明携带credit有害。不能把现有设计直接标记为bug。

唯一干预：保留五个已经固定的同种子mean4模型、19动作及固定AI队友；仍使用balanced。当且仅当首次观测到completed_passes从0变为正数，在下一次选择动作前将BalancedInference重置为初始状态。每回合最多重置一次。其他控球变化、sticky状态、概率、动作空间和奖励均不改；不把主要球员委托给内置AI。

先以实验工具在旧200验证场景执行原balanced回放，逐回合与已审计mean4原日志完全匹配（含步数、分数和配合计数）；再执行阶段重置，五模型共1000干预回合。零优化器更新。不会依据两批失败确认来挑选场景或每种子策略。

固定进入后续确认的门槛：候选总进球至少970/1000，每种子及每几何类型至少180/200，每种子传球/配合进球均至少40/200，且比同场景原mean4总进球至少多10。原主确认93%/逐种子85%/每类85%/配合20%/交叉配对区间下限>0全部保留，不放宽任何规则。

预算：构建辅助工具每次180秒，每次200回合评估300秒，总命令墙钟3600秒，观测子进程RSS512MiB，输出128MiB；全部重任务串行。固定单一规则，不评估其他重置频率、credit衰减或挑选不同种子推理模式。

若验证通过，才考虑作为有独立状态版本的正式推理模式进入生产，保留原DIC1/FPOL和旧模式行为；必须补充跨进程推理恢复、坏状态拒绝、当前源码完整质量与安装检查。生产改动后FPPO仍受严格source/build/ABI/resource限制，旧FPPO不能直接当作新源码可恢复状态。未来独立确认需新登记、排除所有历史及两批失败确认。

若验证失败，保存全部配对日志，不打开新确认、不继续搜索其他reset规则；回到实际失败机制证据。该实验即使通过，也不能替代主确认、一小时持续训练或独立归档交付。
