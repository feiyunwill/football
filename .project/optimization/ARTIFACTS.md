# 源码与验收产物的版本控制

Git 保留源码、构建与测试脚本、运行所需资源（包括动画）、测试输入与基准、验收规则、结构化报告和审查文档。`baselines/` 中用于对照验证的归档与历史二进制属于显式测试输入，本次保留。发布验收要求提交的三份 `product_soak_*.zip` 正式长时测试归档也保留。

优化验收保留当前各检查 JSON 报告直接引用的 32 份日志。日志文件由忽略规则默认排除；更新报告时，应核对其 `log_sha256`，并使用 `git add -f -- <日志路径>` 显式提交配套日志。替换后的旧日志如无继续保留的需要，可用 `git rm --cached -- <旧日志路径>` 移出版本控制。

历史重复日志、诊断加载映射、原始 RGB 帧与状态、运行结果压缩包、临时二进制和锁文件保留本地，默认不提交。代理心跳、活动任务和运行快照同样属于本地状态；协调脚本与里程碑定义继续保留。

2026-10-15 清理将 1,602 个文件（约 292 MB）移出 Git 跟踪，未删除或移动本地文件。此前的完整产物清单 `artifact-inventory-20261015.json` 也作为本地归档保留。独立原生训练验收包未在此次精简范围内。

报告中指向本地产物的路径在普通克隆中可能不可用。需要完整复核时，应单独传递对应产物并核对报告摘要；历史结果不能替代当前源码和目标平台上的重新验收。诊断目录中的实验 shader 和补丁仅供分析，不会自动应用到引擎。

本次通过新提交移出文件，不重写已有 Git 历史，因此不会缩小历史对象占用。运行资源、基准输入与源码均保持不变。
