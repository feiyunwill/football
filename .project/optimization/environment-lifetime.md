# 环境生命周期契约

2026-09-09，`task-20.1.1.2`。

`GameEnv` 独占 `GameContext`，禁止复制和移动。`close()` 幂等，析构自动调用它；关闭后允许重新启动。未启动或关闭后的模拟和读取入口返回异常，重复启动不会覆盖正在运行的比赛。

每个公开操作用 `ContextHolder` 选择当前环境并锁定该实例。退出时恢复调用方的 TLS 和图形上下文；同实例嵌套不会提前解除绑定。不同环境可交错调用或由不同工作线程推进。同一环境的调用按实例锁串行化。配置对象、原始 `context` 指针和内部 OOP/ECS 引用仍属于调用方需保持生命周期的内部接口，不能跨关闭操作保留使用。

销毁顺序为比赛及菜单任务、控制器、缓存节点、场景和资源管理器，最后是图形系统与上下文。场景回调执行时当前环境和渲染器仍有效。GUI 当前页面先从 `PagePath` 释放，再删除根节点，防止页面重复释放。

字体和 SDL/EGL 资源按所有者管理：字体流由 TTF 接管，TTF 初始化成对释放；无头环境不会全局调用 `SDL_Quit`；SDL 渲染器释放自己的窗口、上下文和视频初始化引用；EGL 显示连接仅在最后一个使用者退出时终止。GL 函数表按上下文保存、按线程选择。

引擎不安装进程信号处理器、不重置宿主 C 随机数发生器。草皮噪声使用局部随机数发生器，模拟随机数继续属于 `GameContext`。场景配置先复制再转换坐标，重复 reset 不会修改传入配置。

着色器编译和链接失败抛出带诊断的异常，启动路径清理部分初始化的环境后允许重试。为实际验证图形启动，本任务同时修复了 IBL 的错误整数常量、SSR 的深度采样类型与空间不匹配、IBL 采样器名称、程序绑定缓存不同步。当前着色器中未生效的 uniform 初始化调用保留为注释，不再制造启动错误日志；这不代表对应效果已经完成产品验收。
