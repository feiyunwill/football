# O23 候选草案：扩大2v1训练起点覆盖

本文件在O22试运行结束前为草案。训练预算须根据实测值补齐并冻结后，才可启动完整实验；目前未开始O23训练或新确认。

## 证据与假设

旧验证集balanced共1000回合，899个成功、101个失败。失败中50个已观测传球完成但未进球，41个有请求而无完成观测，10个无请求；没有超时失败。边路与队友变化组分别86.5%和86.0%。请求、完成与终止原因存在观测局限，不能直接推断具体失误机制。

生产 `ApplyPpoStart` 的2v1训练仅有12个有限几何点。候选假设是：扩大开局分布可能改善变化位置的传球与后续进攻。本轮只比较一个训练候选，不再调整已接受的balanced推理控制器。

## 固定对照

- 基线：原有2v1的12点训练分布。
- 唯一候选 `broad80`：20%回合保留原训练分布；80%回合按五个几何家族均匀抽样，再在各自范围内连续采样。五类范围沿用已有broad评估分布的定义，但不直接读取验证坐标作为训练点。
- 奖励、观察视图、动作、固定AI队友、网络、PPO参数和更新预算相同。候选独立任务标识及快照schema，严格拒绝跨任务恢复；保留旧任务定义。
- 五个种子42、123、2026、31415、271828，两种配置均从各自种子的相同初始化规则开始。hidden64、epochs4、minibatch64、rollout256、2048次更新、cadence10、episode_limit256。仅使用最后一次更新的模型，不根据验证得分挑检查点。
- 总计10个完整训练运行，串行。先执行当前版本短训练试运行以登记时间、资源和磁盘上限，再冻结完整协议。

## 验证与确认隔离

现有200个broad场景只作验证；旧O20确认集已用于回归，不再视作未来独立确认。候选验证门槛预定为均值至少92%、每种子至少83%、每组跨模型至少82%，每模型完成传球和配合进球率至少20%，均值比匹配的新训练基线至少高2个百分点。

只有验证通过后才冻结候选及工具，登记全新200个几何点与引擎种子。随后按八周计划的93%均值、每种子85%、每组85%、配合指标和相对冻结O20模型的配对置信区间门槛进行一次独立确认。原始采样、随机和内置AI作为对照保留；不宣称已超过内置AI。

失败保留；不替换训练种子、不延长某个失败模型的更新数、不按确认结果调整分布或门槛。训练几何和引擎种子需要可核验记录或确定性重建，确认登记时排除已记录训练/历史确认数据，并说明无法排除的范围。
