# O23 schema9 paired-control diagnostic

This diagnostic compares schema9 with its schema6 ancestor using a fresh seed-42 64-update run, split 32+32, identical PPO hyperparameters, and the same pilot-only holdout evaluation registration (partition `holdout`, evaluation seed `904729`, 64 episodes). Each schema records its own resulting fifth-group subset because the sampler distributions deliberately differ.

It has no acceptance authority. It does not use validation, confirmation, replication, or prospective cases; it cannot alter frozen O23 gates or enable O24/O25. It records checkpoint incompatibility, resume equivalence, resource limits, and fifth-group score, completed-pass, and joint metrics for a paired descriptive comparison.
