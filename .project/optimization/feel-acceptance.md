# 手感产品验收契约

对应 `ms-22.1 → plan-22.1.2 → task-22.1.2.2`。正式入口是 `python3 .project/quality.py run task-22.1.2.2`，最后执行 `.project/gates/feel_regression.py`。前置的输入、固定步长和平滑检查必须针对当前源码通过；手感检查失败时，任务和里程碑保持未完成。

检查器重新构建 Release `standalone_game`、核心引擎及窗口跟踪库，在私有 X11 命名空间中启动真实产品，要求进程实际映射指定的核心库和私有 D3D12 驱动。固定种子 42–56，每场四次 XTEST 按键，共 60 次。每次按键都必须在比赛进行中进入同一受控球员的逻辑步进，记录该球员沿按键方向的人工命令及已接受的动作。动作可以是移动动画；若为停球或控球动画，必须在该次选择之后观察到同一球员的真实主动触球，才可作为响应的因果起点。在因果起点之后，必须观察到沿按键方向至少 0.1 m/s 的真实速度增量，随后出现产品窗口交换。速度增量同时相对按键前和动画选择前的实测速度计算，避免旧动画的惯性被误判为本次按键响应。以按键时间为起点，从全部 60 次原始样本重新计算最近秩 p95；球员速度变化与首次可见交换都不得超过 50 ms。按键期间若渲染阻塞到没有逻辑步进，记为失败样本并记录阻塞时长；缺失响应不从分布中剔除。

若自动换人发生在物理按键和首次接纳该输入的逻辑步之间，测量对象是该逻辑步实际受控的后继球员，并同时记录按键前与接纳时的球员编号。后继球员必须有同方向 HID 的真实人工命令；其首个命令记录的实际速度作为换人前基线，动画选择前最后一个命令记录的实际速度作为因果基线。仍须观察到同一后继球员已接受的动作、两个基线之后沿输入方向的实际速度变化及随后产品交换。没有命令或未接受动作的换人样本继续失败，不能把别的球员惯性当作响应。

每场保留按键时刻、逐帧步进、命令与动画选择、实际球员速度、窗口交换和产品日志，并验证逐场报告、跟踪源、加载的二进制和驱动 SHA-256。完整原始目录打包到 `.project/optimization/evidence/feel_regression-*.tar.gz`，不以摘要代替原始事件。正式输出另有 `triage.json`：按每次按键的原始命令和动画事件标注辅助方向冲突、触球锁定、迟取命令、动画选择、物理响应或呈现延迟等可能原因。分类是诊断推断，仅供定位，不改变 50 ms 验收阈值或失败判定。

2026-10-01 的多次因果检查均观察到大量缺失响应，已响应样本 p95 也远超 50 ms；每次运行的精确数字和源码哈希以该次报告为准。此前未要求命令与动画因果链的检查曾报告 55/60 次速度变化，其中包含旧动画造成的变化，不能作为产品响应数。停球 `touch_pending` 阶段的移动命令和真实速度长尾仍需修复，不得通过改写阈值、遗漏按键或提前打断触球动画使检查变绿。

2026-10-01 隔离实验分支 `experiment/feel-manual-assisted-turn-20261001` 的完整 15 场诊断观察到 60/60 次按键被采样并产生速度响应，但速度 p95 为 65.508 ms、可见交换 p95 为 68.605 ms，仍未达到正式 50 ms 门槛。SDL 取到按键的 p95 为 4.923 ms，逻辑输入接纳 p95 为 36.43 ms；4358 帧配对记录显示渲染中位耗时 14.911 ms，其中窗口交换中位耗时 12.048 ms，交换间隔为 0。该私有 WSL D3D12 路径的数据仅用于定位，不能代替目标 GPU 的渲染验收。另有接触前动画锁定造成约 227.572 ms 的速度响应长尾。逐帧数据、二进制哈希与省略 PPM 的原始事件归档见该分支的 `feel_swap_poll_decomposition_20261001.json` 和 `feel_swap_poll_cohort_20261001.tar.gz`。降低新按键方向判据的候选虽改善单场样本，却在完整样本中出现 59/60 响应、64.13 ms 的 p95，已撤销并归档。后续需同时解决保留真实触球的动画响应和呈现阻塞，再重跑正式验收。

2026-10-04 的当前候选在换人时等待继承的传球／射门键释放，避免把旧按键缓冲为新球员动作；反向手动输入在换人混合阶段保留方向，低速命令不再被自动朝向覆盖。产品探测只在比赛进行且存在受控球员的近期逻辑步进后发出测量按键；遇到己方定位球时使用真实短传键恢复比赛，并记录等待与恢复输入。独立完整探测 `benchmarks/feel-regression-1791060254018192282/report.json` 覆盖 15 场、60/60 次速度响应、449 项断言、零跳过，速度 p95 为 35.19 ms、可见交换 p95 为 39.13 ms。它保留一次较慢的物理响应诊断；该独立探测不替代包含 ECS、长赛、输入和渲染依赖的正式任务收据。

自动换人因果分析修复后的独立完整采样见 `benchmarks/feel-regression-1791074423492047754/report.json`，再次覆盖 15 场、60/60 次接纳及真实速度响应、449 项断言、零跳过；速度 p95 为 36.34 ms、可见交换 p95 为 39.224 ms。两次较慢样本在诊断中分别归为迟取命令和物理响应延迟，原始窗口事件保留在对应归档。任务入口的正式完整采样见 `benchmarks/feel-regression-1791074638271530578/report.json`，15 场 60/60 次响应、449 项断言、零跳过，速度 p95 为 34.731 ms、可见交换 p95 为 37.419 ms，诊断未记录因果违规；该正式收据只证明手感任务及其当前依赖链，不代表全部优化阶段完成。
