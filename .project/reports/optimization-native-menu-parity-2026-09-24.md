| 行为 | 现有菜单路径 | 当前原生入口 | 必须补齐的验收 |
| --- | --- | --- | --- |
| Host/Join 路由 | 直接或通过 run_graphical 创建 HostedMatch / NetworkPlayer | CMake 公共别名选择 C++ 可执行程序 | 从真正菜单发起并证明使用预期原生进程、传输与共享引擎；不能只运行二进制 |
| K 暂停 | HostedMatch.set_paused 调用服务器暂停 | RunNativeClient 切换本地 controls_paused，暂停输入采样 | 主机暂停须冻结权威模拟，保持窗口、心跳与退出响应；客户端不能改变全局暂停；恢复时清理旧输入并经过同步屏障 |
| P 保存 | 捕获权威状态并写入检查点，Resume 使用该路径继续比赛 | client.save_replay(false) 保存回放 | 保存、退出、从菜单恢复后状态一致并可继续对局；检查点与回放的产品行为分别验证 |
| 自动端口 | Host 支持端口 0，并公布实际 listen_port | 候选服务端明确拒绝端口 0 | 由实际绑定得到可连接端口，不能用“预先找空闲端口后关闭”模拟原子分配 |
| 场景与档案选项 | Host 接收场景、左右控制数量、种子、回放及检查点路径 | 服务端 CLI 为 port/left/right/seed/slots；客户端为 host/port/left/right/seed/headless/frames | 对菜单现有选项建立明确映射，错误须在启动前反馈；不能忽略场景或输出路径 |
| 图形与输入生命周期 | 图形协调器拥有 UI，工作线程持有模拟、网络和档案对象；退出会等待所有者清理 | 原生循环拥有独立窗口与输入、传输工作逻辑 | 实际窗口、键盘及手柄验证等待、暂停、恢复、断线、退出；不得只验证命令行参数 |
| 回放 | Replay 菜单调用 playback，图形回放有独立结束与取消流程 | 已有独立原生保存段回放证据 | 从真实菜单选择用户录制文件并完成验证/取消；FTAC 权威观测文件不能替代用户回放产品路径 |
