# PBR/IBL 正式源码采纳与原生契约验证

归属 ms-12.3、ms-24.1 → plan-24.1.1 → task-24.1.1.1。已把隔离候选中验证过的 4 个渲染器文件与 15 个着色器文件采纳到正式工程；没有复制候选工作区中的其他网络、构建或测试文件。采纳前原件、逐文件哈希与来源记录在 `native-pbr-ibl-adoption-preparation-20260928-a/plan.json`。

候选实现修正了 PBR 几何与延迟直接光照的矩阵、G-buffer、材质批次和线性 HDR 接口；创建程序化环境立方体、漫反射辐照立方体、GGX 预滤波立方体及 BRDF LUT，在 IBL 合成时实际绑定，并在渲染器析构及变光重建时释放资源。隔离阶段已分别验证真实纹理数值、采样器绑定、受控 M/R/AO、同纹理异材质，以及同一上下文的变光重建，详见先前三份报告。

`native-pbr-ibl-canonical-validation-20260928-a` 对正式源码重新进行 Release 与完整 Debug 全量构建，再运行 Legacy/PBR 四个真实 EGL GameEnv 捕获。四案例各 174 项、共 696 项断言通过；每案例五帧完整 RGB 和模拟状态与已验证隔离候选逐字节相同，两种构建之间也逐字节相同。完整 Debug 的 `-g`、ASan/UBSan、禁止恢复和帧指针编译标志均经编译命令检查。独立终态核验 6,730 份固定输入、977 份正式引擎文件、8 份命令日志、父命名空间与执行进程，阶段退出 0。

`native-pbr-ibl-contracts-validation-20260928-a` 在另一个新构建目录中编译原仓库的运行时、姿态与帧捕获契约目标，并执行六个案例，合计 25,285 项断言通过。Legacy/PBR 姿态各覆盖 8 组卡片状态、6 张画面；两种模式的实际帧捕获各执行 161 模拟帧及 174 项断言。独立终态核验 6,788 份输入、977 份正式引擎文件和 8 份命令日志，阶段退出 0。

**当前验收边界：** 正式质量配置中的 `pbr_pipeline`、`postprocessing` 与 `render_regression` 仍为未就绪；外部 HDR 环境贴图、实际窗口与 1080p 硬件帧时间、完整后处理开关及原网络/状态/输入/AI/发布门禁尚未通过。正式源码采纳不等于产品级里程碑完成，八个优化里程碑仍按质量工具保持 `stale`。
