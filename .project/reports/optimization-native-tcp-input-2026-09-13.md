# 原生 TCP 缓存输入的真实套接字验证

2026-09-13。归属 ms-22.1 → plan-22.1.1 → 输入接入任务，并为 ms-23.1 的权威输入窗口提供局部证据。独立阶段 D 已成功终止，Release 四组场景通过 1179 条断言，ASan／UBSan 四组通过 1163 条断言，均零跳过。计数包含实际 IO 等待观察，因此不宣称它们是不同的功能用例。两种构建的测试分别耗时 4.930／117.352 秒。

每种构建覆盖种子 42／43、单槽位／双槽位四组场景。每组通过 29 个真实权威 GameEnv 状态哈希、27 次唯一输入发送和完整的子进程退出检查。单槽位场景各完成 25 次远端预测纠正；双槽位的全部自有输入保持相同。等待期间的短按保留到下一新帧，发送、预测和历史使用相同输入；追帧后首个发送绑定实际帧 3。释放后的后续输入为完整中性状态，套接字关闭后客户端停止并报告失败。

[实际报告](../optimization/benchmarks/native-network-input-20260913-d/evidence/report.json) SHA256 为 ab5d98245e78d6c1e98a6142b3b9153c939ec57a6aff249d4e65bd92b47d23ee。[独立收据](../optimization/benchmarks/native-network-input-20260913-d/verification.json)已核验 1227 个文件，SHA256 为 9980ddd3bebe1ff86204a31318e5bf7b26b4bf8d28c16236dccc7db36b430aab，覆盖输入／权威／哈希原始字节、命令记录、日志、核心、独立可执行文件和失败阶段 A／B／C。

[共享发送入口](../optimization/benchmarks/native-network-input-20260913-d/integrated_client.cpp)在权威处理后的供应回调中读取有界 LocalInputHistory，仅在首次接纳时消费 NativeInputBuffer 并发送。新增带锁的只读权威／哈希队列计数，让验证程序观察实际解析完成，不修改队列或推进逻辑。独立编译使用当前真实客户端的编译／链接参数，以及已经验证的核心和精确固定的头文件覆盖。

三个失败阶段均保留：A 在测试程序尚未轮询私有 IO 时等待已排队的 Ready，发生超时；B 把一次 20 ms 无数据读取视为发送完成；C 在仅两帧解析完成时预期三帧追帧。D 以实际解析计数及具体发送帧为完成条件，保持输入、唯一发送、完整哈希和子进程退出要求；没有把等待时间作为到达证据，也不对 TCP 交付时间作机制归因。

本轮是受控 TCP 协议对端、真实客户端和独立权威 GameEnv 的组合。对端不是产品服务器，不覆盖 UDP、产品主循环、WAN、重连或物理输入延迟。UDP 发送入口仍为未编译的准备代码；三个主循环仍需完成实际接入、图像／呈现计数和节拍验收，因此输入与网络里程碑整体状态不提升。
