## 顶点去重候选

把每个身体子网格的逐项线性去重改为位置/纹理坐标的稳定索引，仅为首次出现的顶点构造完整属性。保留首次插入顺序、正负零等价、NaN 不合并及无穷值比较语义。

Release 与完整 Debug ASan/UBSan 各通过 7 项契约。两个种子、三种核心、两种构建共 12 次真实 GameEnv 运行，每次 1000 帧及 500 帧快照回放一致；真实身体模型输入、唯一顶点、权重、索引、关节及输出逐字节一致。

本轮实际服务端启动：Release 原实现 0.570 秒、候选 1.179 秒；Debug 原实现超过原 30 秒期限，候选 26.810 秒。其他运行耗时波动明显，不能从单次启动推断稳定收益；暂不采用此候选。见[完整证据](../optimization/benchmarks/native-body-vertex-index-20260921-a/report.json)。

## 当前加载成本

针对当前原实现同时测量实际耗时与主线程 CPU 时间。Debug 两个种子的启动 CPU 为 24.609 / 16.610 秒，19 次 ASE 解析消耗 4.726 / 3.244 秒，约占两成；身体准备整体仅为 0.813 / 0.306 秒。解析和构建、动画及玩家初始化均需持续优化。

该诊断保留实际资源工作和初始状态哈希；90 秒仅为诊断收集的看门狗，产品启动标准仍是 30 秒。见[逐段时间和 CPU 记录](../optimization/benchmarks/native-startup-cost-profile-20260921-a/report.json)。

## ASE 解析器候选

旧实现已在实际导出函数中复现两处问题：末尾没有换行时越过输入边界；长行写出固定 2048 字节数组。候选使用有界扫描和字符串视图，取消中间令牌复制，以 RAII 管理尚未交付的树/节点，并将嵌套深度限制为 256。

保留原有名称、空白与引号拆分、CR/NUL 处理、节点顺序以及提前结束时的输入游标语义。Release / Debug 各 11 项契约通过，无跳过；候选两个原缺陷输入也都正常解析，未关闭泄漏检测。

全部 24 个真实 ASE 文件共 229823 个节点在原实现/候选、两种构建间完整序列化一致。解析 CPU 单次观察为 Release 0.397142 → 0.171271 秒，Debug 27.4468 → 5.85546 秒；这些是观察值，不替代固定统计性能验收。

四次真实引擎验证，每次 1000 帧和 500 帧检查点回放，状态哈希与既有原核心一致；身体模型输入/输出也逐字节一致。本轮实际服务端启动均在 30 秒内：Release 原实现/候选 1.423 / 2.153 秒，Debug 22.914 / 15.112 秒。实际模型与场景覆盖不等于全平台或长期性能验收。见[实现和完整结果](../optimization/benchmarks/native-ase-parser-20260921-a/report.json)。
