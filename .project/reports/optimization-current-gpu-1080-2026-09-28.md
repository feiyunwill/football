# 当前源码 1080p 硬件渲染预检与窗口瓶颈

归属 ms-24.1 → plan-24.1.2 → task-24.1.2.2。使用提交 `87a3c8fc24ba362d14fe0aa275aab2d68429217c` 的正式引擎 Release 构建（核心 SHA-256 `f225d3aebe1315c6479f82ad834e86842e17db0aeab0fa2f7410ae222f68e1f1`），在 Intel Arc 140T / D3D12 及私有修复版 Mesa 26.2.2 上测量 1920×1080。实际加载的私有 Gallium SHA-256 为 `46e392bcd6aafc9abeeb1aed1874fa47cb60e1b30665d5da818c14fc5e35f998`，驱动尚未作为产品依赖打包。所有运行保持 161 个逻辑帧和 62 个比赛中帧；在五个固定状态各绘制 12 次，前四次预热，得到每进程 40 个计时样本。p95 为排序后第 floor(0.95×39) 项。计时包括 `env.render()`、窗口交换或离屏呈现以及 `glFinish()`，诊断取帧位于计时之外；启用产品 RGB 缓存的对照则把同步回读包含在计时内。

离屏预检的关闭回读路径达到 16.67ms 预算，但窗口两轮均未达到，不能用离屏值替代产品验收。窗口使用独立私有挂载命名空间与 Xvfb，不改宿主 X11 socket；测试结束后 Xvfb 子进程已回收，父命名空间不变。每组进程实际 GL renderer 均为 `D3D12 (Intel(R) Arc(TM) 140T GPU (16GB))`，并核对当前引擎核心和私有驱动加载路径。两轮同设置的五帧 RGB 及全部模拟状态逐字节一致。PBR 默认/完整效果的离屏与窗口五帧 RGB 也逐字节一致；Legacy 离屏与窗口每帧约 206 万像素不同，窗口更亮。该差异的具体色彩空间原因尚未证实，不将它描述为已修复。第 160 帧缩略预览：[离屏 Legacy](assets/gpu-1080-offscreen_legacy-frame160.png)、[窗口 Legacy](assets/gpu-1080-window_legacy-frame160.png)；原始比较使用 1920×1080 RGB。

随后在另一独立窗口阶段用 `SDL_GL_SwapWindow` 入口探针和未插桩 ABBA 对照拆分耗时。两组 Legacy 探针的交换调用平均 15.36/13.75ms，PBR 完整效果为 11.89/14.21ms，占探针运行整帧平均的约 81%–86%；交换间隔均为 0，随后的 `glFinish()` 平均只有 0.012–0.016ms。交换调用包含先前排队的 GPU 工作和驱动等待，不能把这部分全归咎于窗口 API；探针与未插桩的画面/状态一致，但跨进程 p95 波动明显。下一步需在同一 D3D12 窗口内测量关键绘制通道与 GPU 完成，再决定针对 Legacy SSAO、PBR 后处理或呈现路径的具体改动。

再做 GLX 与请求 `SDL_VIDEO_X11_FORCE_EGL=1` 的成对对照：两路径五帧 RGB/状态相同，但 Legacy 请求 EGL 两轮 p95 21.61/23.25ms，对照 GLX 为 19.66/19.30ms；PBR 完整效果请求 EGL 为 25.56/26.46ms，GLX 为 18.45/26.52ms。没有稳定收益，未改正式窗口后端。这里记录的是 SDL EGL 请求，尚未用独立 API 拦截证明每次上下文的具体后端。

四个阶段的原始 40 样本数组、实际身份、图像对照、报告 SHA 和终态核验已汇入[机器可读证据](../optimization/evidence/native_current_gpu_1080_20260928.json)。本地完整脚本、命令日志、原始 1080p RGB 和失败记录保留于忽略的 `native-current-gpu-1080-20260928-a`、`native-current-gpu-window-20260928-a`、`native-current-gpu-window-profile-20260928-a`、`native-current-gpu-window-egl-20260928-a` 阶段；逐阶段独立核验 827 份源码哈希、104/127/134/127 份固定输入、9/10/11/10 份命令日志、进程终态、私有服务器回收与父命名空间。正式 `render_regression` 仍为 `ready:false`，未把诊断当成产品级通过。

范围限制：这些是固定状态、私有驱动和私有 Xvfb 的 GPU/窗口预检，不是连续比赛、正式打包驱动或物理显示延迟验收；未在 1080p 执行 ASan/UBSan。窗口 p95 超过 16.67ms，Legacy 色彩差异未定位，故 task-24.1.2.2 与 ms-24.1 继续未通过。下一轮应在同一窗口把交换内等待与 GPU 着色器/通道成本关联，针对真实瓶颈优化并完成连续比赛及正式运行时复验。
