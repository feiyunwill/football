# PBR 受控材质与 G-buffer 响应验证

归属 ms-12.3、ms-24.1 → plan-24.1.1 → task-24.1.1.1。引擎候选仍在隔离工作区，正式源码未采纳；本报告不提升产品验收状态。

为了验证材质数据确实到达延迟管线，隔离探针在真实 `OpenGLRenderer3D::RenderVertexBuffer` 入口设置 metallic、roughness、AO，并在 PBR 几何 uniform 调用和 IBL 合成前读回材质 G-buffer 附件。分别运行基准 (0,0.5,1)、全金属 (1,0.5,1)、全粗糙 (0,1,1)、AO 为零 (0,0.5,0)，以及同纹理相邻索引交替金属度的批次。未修改引擎候选源码或正式源码。

Release 与完整 Debug 各五个真实 EGL GameEnv 捕获，共 10 案例、1,740 项断言通过；每案例 161 模拟帧、五份完整 RGB/状态、原捕获/恢复/无窗口检查均通过。两种配置中每个案例的五帧 RGB 与状态逐字节相同，状态也与未注入材质的固定输入相同，未出现 uniform 缺失。基准的 58,101 个材质附件像素全部为 M=0、R=0.5、AO=1；单项变化时，对应通道的 58,101 个像素全部切换到目标值。三种单项变化相对基准每帧分别改变约 57,938–58,020 个完整 RGB 像素。

同纹理异材质案例每次捕获检测到 32,754 对相邻同纹理索引；材质 uniform 呈现两组值，几何批次分割使 uniform 调用从基准的 3,129 次增加到 16,305 次。首个 G-buffer 读回同时包含 58,082 个非金属和 19 个金属像素；五帧最终 RGB 分别改变 19、40、101、235、344 个像素。这说明该场景中的不同材质参数未被相同纹理批次吞掉。

保留两次冻结失败：`native-pbr-material-validation-20260928-a` 的驱动误写环境变量名，探针未收到变体；`native-pbr-material-validation-20260928-b` 的 Release 五案例通过，但 Debug 探针缺少引擎 RTTI 链接，进程未进入场景。新阶段 `native-pbr-material-validation-20260928-c` 将 Debug 探针链接到固定的引擎核心，五案例及跨构建比较通过。独立终态核验分别匹配 6,419/6,499/6,584 份固定输入、2/8/6 份命令日志、1,138 份正式源码；所有阶段进程均已结束，父命名空间一致。证据见 `native-pbr-material-progress-20260928-a/terminal-verification.json`。

**剩余边界：** 此处只验证受控 M/R/AO、G-buffer 与画面响应；尚未验证变光 IBL 资源重建、外部环境贴图导入、实际窗口/硬件 p95、所有场景材质或原网络、状态、输入、AI 和发布门禁。候选不得仅凭这些隔离案例进入产品完成状态。
