# IBL 资源生成、绑定与释放的隔离验证

归属 ms-12.3 与 ms-24.1 → plan-24.1.1 → task-24.1.1.1。候选仍在隔离工作区，正式源码未采纳，产品验收未通过。

在已验证的延迟 IBL 接口上，候选从场景最强方向光生成程序化 HDR 环境立方体，并在运行时预计算 32² 漫反射辐照度立方体、128² 起始的 GGX 预滤波立方体（5 级 mip）和 128² BRDF LUT。合成时使用纹理槽 4、5、6；纹理在渲染器析构时删除。原退出路径直接删除渲染器而不调用其 Exit，因此析构清理是实际需要的修正。环境资源的光源指纹重建逻辑已经实现，但变光重建尚未单独实测。

首次冻结阶段 `native-ibl-resources-validation-20260928-a` 的 Release/完整 Debug 全量构建、legacy/PBR 四个真实 EGL 捕获均通过，每例 174 项断言、总计 696 项；两种配置的画面与状态逐字节一致。Legacy 五帧完整 RGB 与接口基线相同，PBR 五帧每帧约 58,000 个像素变化，中央球场区域每帧 9,417 个非黑像素；模拟状态不变，uniform 缺失为 0。Release 的实际调用探针在 IBL 合成处取得 15 个快照，确认采样器 4/5/6 与 32/128/128 尺寸纹理；直接 GL 读回显示四种采样目标均为有限、非恒定数值，粗糙 mip 的峰值低于清晰 mip。析构探针观察到三张纹理由存在变为删除。

首次阶段退出 1：Debug 读回探针本身作为首个 `LD_PRELOAD` 库，引发 ASan 加载顺序错误，进程在进入场景前退出。保留该失败及全部日志；新冻结阶段 `native-ibl-resources-continuation-20260928-a` 只调整探针进程的预加载顺序，先加载 libasan，再加载原探针，复用且核验未改动的源码、构建和捕获输入。随后 Debug 的读回及独立绑定探针各通过 174 项实际场景断言；纹理数值、采样器绑定、析构删除与 Release 一致，探针画面及状态与无探针 Debug 捕获逐字节相同。

独立终态复核：首次阶段 6,355 份固定输入、13 份命令日志；延续阶段 6,406 份固定输入、2 份命令日志；1,138 份正式源码均匹配，父命名空间一致，执行进程已终态。证据见 `native-ibl-resources-progress-20260928-a/terminal-verification.json`；源码差异见首次冻结阶段 `change.diff`。

**未完成：** 该环境为程序化生成，尚未验证外部环境贴图导入、受控材质 M/R/AO 响应、同纹理异材质批次、变光资源重建、实际窗口与整帧 p95，以及原网络、状态、输入、AI 和发布门禁。因此不提高 ms-12.3、ms-24.1 或产品质量状态。
