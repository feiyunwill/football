# 当前源码的比赛基准与 ECS 配对复验

归属 ms-21.1 → plan-21.1.1 → task-21.1.1.1／task-21.1.1.2。2026-10-03 在当前源码上用正式质量入口依次运行 `python3 .project/quality.py run task-21.1.1.1` 和 `python3 .project/quality.py run task-21.1.1.2`，两项均由质量系统判定 `verified`。硬件为 WSL2 内的 Intel Core Ultra 9 285H；完整机器、编译、源码和二进制身份写在原始报告中。

真实 11v11 比赛基准对种子 42、43 各执行五个独立进程，每进程预热 200 帧、计时 2,000 帧。启动与稳态分开，计时区间只含 `StepWithInput`；两种子各 10,000 个稳态样本的状态哈希在进程间一致。

| 种子 | 启动 p50 | 稳态 p50 / p95 / p99 | 最大观测 RSS | 最大 RSS 增长 |
| --- | ---: | ---: | ---: | ---: |
| 42 | 141.012ms | 2.072 / 3.481 / 4.457ms | 89,055,232 B | 40,960 B |
| 43 | 151.199ms | 2.195 / 3.916 / 5.136ms | 89,038,848 B | 40,960 B |

ECS 门禁以仓库内的不可变 `ecs_v7` 参考为基线，两种子各做 15 对独立比赛，固定输入和状态轨迹一致；完整合同完成 1,590,027 条断言、零跳过。种子 42 的 CPU 几何比值为 0.8225，95% bootstrap 区间上界 0.8378；种子 43 分别为 0.8597 和 0.9065。两者上界均小于 1，分配和 p99 条件亦通过。种子 43 有一对 CPU 比值 1.1268，保留在原始样本中；结果支持整组统计收益，不表示每一对都提速。
