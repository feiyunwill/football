# PBR 自动曝光与正式后处理门禁

归属 ms-24.1 → plan-24.1.1 → task-24.1.1.2。本次在正式 PBR 渲染路径接入 GPU 自动曝光：着色器对当前 HDR 纹理做 16×16 分层采样，以几何平均亮度求 18% 灰目标曝光，并将结果限制在 0.1–8.0；两张 1×1 RGBA16F 纹理轮流保存曝光历史，每次模拟时间变化以 0.125 系数适应。色调映射从当前曝光纹理采样，先合成 HDR Bloom，再统一应用曝光。通过 `GFOOTBALL_PBR_AUTO_EXPOSURE=1` 启用；默认关闭，手动曝光和此前默认画面保持原行为。新增纹理与 FBO 随视图删除。

初版按每次绘制推进曝光，`native-auto-exposure-capture-20260928-a` 的现有帧捕获契约指出同一模拟状态再次呈现时画面改变。保留失败阶段后，改用快照持有的 `Match::GetActualTime_ms()` 控制更新，在新阶段 `native-auto-exposure-time-capture-20260928-a` 通过基线、自动和组合效果的实际 GameEnv 捕获。测试探针仅在验证时读取 1×1 纹理；正式渲染不做 CPU 回读。

正式 `postprocessing` 门禁使用全新 Release 和完整 Debug ASan/UBSan 构建，两种配置各执行 13 个真实 GameEnv 软件 EGL 案例，共 26 例、4,524 项断言，跳过 0 项，完整 RGB 与模拟状态跨配置逐字节一致。覆盖 Legacy 隔离、Bloom/FXAA/曝光独立与组合对照、探针透明性、手动曝光单调性以及自动曝光优先级。每种配置的 GL 探针确认组合效果 15 轮提取→横/纵模糊→色调映射→FXAA；自动曝光为 5 次 GPU 更新对应 15 次色调映射，同一模拟状态重复呈现保持曝光不变；曝光目标与亮度满足约 0.18 的关系，并按 0.125 系数适应。五张新增纹理及五个 FBO 按启用模式创建，视图删除后均被释放。
