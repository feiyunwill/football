已执行的检查包括：

- 同时按住 W、Shift、V，持续按住不重复产生按下边沿，释放后清空。
- 两次轮询间完成 V 的按下与释放，短按保留一次且不重复。
- 虚拟手柄接入、摇杆归一化及 Y 轴翻转、按钮持续状态与单次按下边沿。
- 两个真实窗口的焦点转移，失焦时屏蔽方向和按钮，恢复焦点后继续采样。
- 手柄拔除后清空轴及按钮，多次关闭采样器保持有效。

预检 A 和增加阶段诊断的 B 都在返回原窗口时失败，原日志及失败退出码完整保留。C 在保留 SDL 焦点请求的同时，显式设置并查询 X11 服务端的焦点，保留原焦点断言。日志显示返回时 X11 焦点仍为第二窗口 `2097169`，显式请求后为原窗口 `2097167`，SDL 随后正确观察到恢复。该结果验证了实际焦点转移下的采样行为，不能据此认定桌面窗口管理器下 SDL 焦点 API 存在缺陷。

三个批次都在独立挂载命名空间启动私有 Xvfb，使用私有认证文件并关闭 TCP 监听。所有 X 服务均已回收，父命名空间、原 `/tmp/.X11-unix` 权限和 `/usr/bin/xkbcomp` 的状态逐项保持一致。未安装或升级宿主包。A 在正式框架回归期间执行，B／C 在架构正确性检查期间执行，均早于正式 CPU 计时。
